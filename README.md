# СВЕТ: магазин светильников

Контрольная работа №1 по дисциплине «Фронтенд и бэкенд разработка».
Тема: «HTML и CSS: разработка многостраничного сайта».

**ФИО:** Филиппов К.А.

**Группа:** ЭФБО-13-25.

**Репозиторий:** https://github.com/aka-rei/kr1-html-css-shop

## О проекте

Учебный магазин настольных светильников. Реализованы:
пять страниц, навигация, карточки, таблица, форма и модальное окно.

## Структура и страницы

```text
kr1-html-css-shop/
├── index.html         # Главная: первый блок, преимущества, популярные товары
├── catalog.html       # Карточки, категории и статический блок фильтров
├── product.html       # Описания, цены, характеристики и кнопки заявки
├── order.html         # Форма заявки
├── contacts.html      # Контакты и ссылка на форму
├── css/
│   └── style.css      # Общие стили пяти страниц
├── js/
│   └── main.js        # Открытие и закрытие модального окна
├── images/            # Изображения трёх моделей
├── README.md
└── .gitignore
```

## Просмотр

Сайт открывается через `index.html` в браузере. Установка и сборка не нужны.

## Технологии

HTML5, CSS3, CSS-переменные, Flexbox, Grid, базовый БЭМ.
JavaScript используется только для модального окна через `dialog`.

## Особенности реализации

Бейдж «Новинка» показывает работу `absolute` внутри карточки с `relative`.
Шапка использует `sticky` и `z-index`. Таблица содержит характеристики трёх моделей.

Фильтры являются статическим макетом. Форму проверяет браузер через `required`
и `type="email"`. Метод GET добавляет значения в адрес и открывает ту же страницу.
Сохранения и реальной отправки заявок нет.

Товары, цены и контакты демонстрационные. Изображения созданы с помощью
генерации изображений для учебного проекта.
