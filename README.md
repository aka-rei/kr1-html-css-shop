# СВЕТ

Учебный HTML/CSS-проект каталога настольных светильников.

КР №1: «HTML и CSS: разработка многостраничного сайта».
**ФИО:** Филиппов К.А. **Группа:** ЭФБО-13-25.

## Структура

- `index.html` — главная страница;
- `catalog.html` — каталог;
- `product.html` — товары и характеристики;
- `order.html` — форма заявки;
- `contacts.html` — контакты;
- `css/style.css` — общие стили;
- `js/main.js` — модальное окно и обработка формы;
- `images/` — изображения проекта.

## Технологии

HTML5, CSS3, Flexbox, Grid, минимальный JavaScript.

## Запуск

Сайт открывается через `index.html`, без установки и сборки.
Форма учебная: данные не сохраняются и не отправляются. Фильтры — статический макет.
