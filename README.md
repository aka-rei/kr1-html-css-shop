# СВЕТ: магазин светильников

Контрольная работа №1 по дисциплине «Фронтенд и бэкенд разработка».
Тема: «HTML и CSS: разработка многостраничного сайта».

**ФИО:** Филиппов К.А.

**Группа:** ЭФБО-13-25.

**Репозиторий:** https://github.com/aka-rei/kr1-html-css-shop

## О проекте

Учебный HTML/CSS-проект каталога настольных светильников «СВЕТ».
Пять страниц с навигацией, карточками товаров, таблицей характеристик,
формой заявки и модальным окном.

## Структура и страницы

```text
kr1-html-css-shop/
├── index.html         # Главная: первый блок, преимущества, популярные товары
├── catalog.html       # Карточки, категории и статический блок фильтров
├── product.html       # Описания, цены, характеристики и кнопки заявки
├── order.html         # Форма заявки
├── contacts.html      # Контакты и ссылка на форму
├── css/
│   └── style.css      # Общие стили пяти страниц
├── js/
│   └── main.js        # Модальное окно и обработка учебной формы
├── images/            # Изображения трёх моделей
├── README.md
└── .gitignore
```

## Просмотр

Сайт открывается через `index.html` в браузере. Установка и сборка не нужны.

## Технологии

HTML5, CSS3, CSS-переменные, Flexbox, Grid, базовый БЭМ и минимальный JavaScript.
Внешние библиотеки и CSS-фреймворки не используются.

## Особенности реализации

Адаптивная сетка перестраивает карточки и колонки на узких экранах.
Бейдж «Новинка» использует `absolute` внутри карточки с `relative`,
шапка — `sticky` и `z-index`. Таблица содержит характеристики трёх моделей
и прокручивается внутри своего блока на телефоне.

Фильтры каталога являются статическим макетом. Модальное окно на странице
товаров открывается через `dialog` и содержит ссылку на форму заявки.

Форму проверяет браузер: обязательные поля, имя длиной 2–50 символов,
e-mail, телефон в формате `+79991234567` и согласие на обработку данных.
JavaScript показывает результат проверки и очищает форму без перезагрузки страницы.
Данные не добавляются в адрес, не сохраняются и не отправляются на сервер.

Товары, цены и контакты демонстрационные. Изображения созданы с помощью
генерации изображений для учебного проекта.
